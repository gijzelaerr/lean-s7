# Agent instructions

Read and follow `CLAUDE.md` as the canonical repository guidance. References
to Claude or Claude Code apply equally to Codex and other coding agents.

## Authorship and attribution

- Always use `Gijs Molenaar <gijsmolenaar@gmail.com>` as the Git author and
  committer identity for this public repository.
- Never identify Codex, Claude, OpenAI, Anthropic, an AI assistant, or another
  agentic programming agent or tool as a commit or pull-request author or
  co-author.
- Never add `Co-Authored-By` trailers, generated-by notices, AI signatures, or
  equivalent attribution to commit messages, commit trailers, pull-request
  titles, or pull-request descriptions. Do not mention OpenAI or any agentic
  programming agent in those fields.
- Before every push, inspect the commits being pushed and verify their author,
  committer, full message, and trailers.
- Do not rewrite already-published history solely to change attribution unless
  the repository owner explicitly requests that rewrite.
