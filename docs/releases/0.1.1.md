# lean-s7 0.1.1

Experimental classic S7comm patch release. **Not PLC-qualified; do not use on
production equipment.** All supported-profile limitations from 0.1.0 remain.

## Fix and regression coverage

- Repair the compound STRING/WSTRING and bit deadline test fixture's 100 ms
  successful-first-stage margin. Tests now use a 3 s shared deadline, a 1 s
  first-stage delay, and a 2.5 s second-stage observation window. The original
  deadline expires in that window; a fresh per-stage deadline does not.
- Repeat all three actual compound deadline scenarios twice in the full suite.
- Add three test-only fresh-budget substitutes, using separate public calls
  instead of one compound operation. The independent peer must reject each
  with its specific second-stage budget-refresh diagnostic. Earlier timeouts,
  crashes, malformed requests, or a successful client cannot satisfy this
  negative control.
- No production client, timeout defaults, protocol codecs or proof contracts
  changed. Version 0.1.0 and its published tag are not rewritten.
- Also widen the two-stage connection/fallback test margins: a 3 s total budget
  with 1 s and 2.5 s peer stages still rejects a fresh second-stage allowance.
  The distinct operation-budget control uses 1 s against a withheld 1.5 s reply.

Validation includes a full clean local build, native tests, all eight exact
corpus reproductions, pinned python-snap7 3.0.0 emulator/fault integration,
independent native Snap7 PDU240/480 profiles, lint/format and workflow checks.
The attached validation record identifies the exact candidate's Linux/macOS
branch and tag CI results; publication waits for both runs to pass.

Use the pinned Lean 4.33.1 toolchain and `v0.1.1` as the Lake dependency revision.
Python and native Snap7 remain test dependencies, not client runtime dependencies.
No prebuilt binary distribution is promised.

This is bounded regression evidence, not a full Client IO/scheduler-equivalence
proof. Physical controller/firmware behavior, hard native socket cancellation,
exactly-once effects and industrial safety remain unqualified. See
`docs/RELEASE.md`, `docs/COMPLETENESS.md` and the 0.1.0 notes for the full profile.
