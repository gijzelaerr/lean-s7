# Seeded generative assurance — 2026-09-24

The extended pure differential campaign passed 1,024 histories and 23,730
events with no divergence. [Coverage counters](session-fuzz-2026-09-24.json)
retain the four seeds (7, 2026, 65535, 23063), event kinds, observed phases,
accept/reject outcomes and retry decisions: 702 permitted and 544 denied.

Reproduce with `python integration/session_fuzz.py --per-seed 256` after building
`lean-s7-fuzz`. The bounded per-change integration suite uses 64 cases per seed:
256 histories and 6,024 events. The independent Python encoder/response builder
supplies requests, mixed success/failure items, odd padding and mutations of
headers, references, counts, lengths, discriminators, truncation and PLC errors.
The actual Lean typed transition function and S7 response decoders produce the
observed trace; the Python oracle produces the independent expected trace.

Generation is deterministic and uses oracle phases to choose useful actions;
it does not send expected traces to Lean. Repeated reconnect failure, allowance
exhaustion, fresh-operation rejection, multiple completed operations, duplicate
write locations and chronological replay uncertainty are represented. Eight
typed-transition theorems separately establish universal pure-model properties;
finite fuzz comparisons are not proofs of full Client IO or Python source.

The native fixture adapter checks batch/event/packet/config bounds. Fourteen
negative controls exercise invalid envelopes, ranges, request identity, event
shapes and packet octets. Its line limit is checked after reading a line: this
is not an adversarial stdin memory-safety claim.

On divergence, the driver minimizes by deleting event blocks and revisiting
earlier deletions, then saves an exclusive-created JSON artifact under `reports`
or the explicit `--failure-output` path. The result is single-deletion-minimal,
not a globally smallest counterexample. A nonmonotonic predicate control guards
against the shrinker bug found during review. Artifacts retain exact config,
seed, case index and remaining packet bytes. Replay via `--replay PATH` is
limited to 64 KiB and 128 events with validated configuration and envelope.
Failed saves retain the original diagnostic/replay content and preserve earlier
files. No protocol-divergence artifact was generated by these campaigns.

A separate actual-client supplement passed 32 live localhost reconnect
conversations at seed 5715779, all outside the fixed 75-case campaign. Reproduce
with `python integration/generative_reconnect.py`; use `--seed N --case I` for
one exact replay. Generation controls check uniqueness/exclusion across 100
seeds. Independent expected connection/send counts and write chronology are
checked alongside the existing exact-wire peer and native public-operation
fixture. Optional failure artifacts are bounded and never overwrite evidence.

This evidence covers selected pure operational histories and bounded live
reconnect profiles. It does not cover every schedule, physical PLC, hard
cancellation, allocation peak or remote side effect. No new production Client
defect was found. The separately confirmed public SZL metadata-consistency gap
was found by decoder audit, fixed and covered by exhaustive boundary tests.
